# Mask to Normal Map Generator

このプログラムは、マスク画像からノーマルマップを生成するツールです。

---

## 特徴

マスク画像のような、明度の差の大きい画像を入力としても立体感のあるノーマルマップを生成することができます。

- パラメータ変更をリアルタイムに反映するプレビュー
- 日本語/英語モードの切り替え
- 入力プレビューの表示/非表示トグル
- 出力先フォルダの指定
- 設定の永続化（アプリ終了時に保存）：言語、出力先、入力プレビュー表示、既定の出力解像度/半径/強度、上書き設定

---

## 使用方法

1. **プログラムの起動**  
   `Normalmap_Generator.exe`をダブルクリックして起動します。

2. **入力ファイルの選択**  
   - 画像（PNGまたはJPEG形式）をウィンドウにドラッグ&ドロップするか、参照ボタンから選択します。
   ※JPEG形式のファイルの拡張子はjpgまたはjpegである必要があります。
   - 本アプリは入力ファイルを変更・保存しません（入力画像は常にそのまま扱います）。

3. **設定の調整（必要な場合）**  
   ***基本設定***
   - **斜面の形状**: 線形、曲線1（対数）、曲線2（指数）から選択します。
   - **半径**: 生成する斜面部分の半径を指定します（正の整数）。
   - **強度**: ノーマルマップの強度を指定します（正の数）。
   - **その他のオプション**:
     - 「斜面生成方向を反転」: 斜面の形成を外向きに行うか内向きに行うかを反転させます。
     - 「斜面生成を無効化」: 斜面生成を無効化し、元画像のピクセルの明度の差を傾きとして扱う単純なノーマルマップ生成を行います。
     - 「同名のファイルがある場合上書きして保存」: 同名のファイルがある場合に出力ファイルの上書きを行うかを設定します。
   
   ***高度な設定***
   - **ノーマルマップタイプ**: DirectX (Y+) または OpenGL (Y-) を選択します。
   - 「中間ファイルを保存」: 画像処理過程で生成されるエッジ画像やハイトマップを保存します。
   - **出力先ディレクトリ**: 生成先を指定できます（未指定の場合は入力ファイルと同階層に `output` フォルダを作成）。
   - **入力プレビューを表示**: 入力画像プレビューの表示/非表示を切り替えます。
   - 「英語モードを有効化」: UI 言語を英語に切り替えます（設定は保存されます）。

   ※必要に応じて設定を調整してください。デフォルト設定でもノーマルマップの生成を行うことができます。

4. **ノーマルマップの生成**  
   「ノーマルマップ生成」ボタンをクリックして処理を開始します。  
   生成されたノーマルマップは PNG 形式で保存されます。出力先ディレクトリを指定した場合はそちらに保存し、未指定の場合は入力と同階層に `output` フォルダを作成して保存します。

5. **プレビューの確認**  
   入力画像と生成されたノーマルマップをプレビューで確認できます。

---

## ライブプレビュー（リアルタイム）

- 画像の読み込みや設定変更に応じて、ノーマルマップのプレビューが自動で更新されます。
- パフォーマンスのため、プレビューの内部処理は常に 512×512 で実行されます（元画像の解像度に依存しません）。表示は入力プレビューの表示領域（約300×300）に合わせて縮小されます。
- 数値入力（半径・強度）はデバウンス制御で、入力が落ち着いたタイミング（約0.6秒無操作）や Enter キー、フォーカス移動時にプレビューが更新されます。チェックボックスやラジオボタンの変更は即時に反映されます。

---

## 入力ファイルについて

処理の都合上、以下の条件を満たすマスク画像を使用するのが最適です。

- **高コントラスト**: 白と黒のコントラストがはっきりしている画像。
- **シンプルな形状**: 複雑すぎない形状のマスク。
- **ノイズが少ない**: ノイズが少ない画像を使用することで、エッジ検出の精度が向上します。
- **解像度**: 必要に応じて適切な解像度に調整してください（高解像度すぎると処理が遅くなる場合があります）。なめらかなノーマルマップを生成するためには、ある程度の解像度が必要です（2K以上推奨）。

例:  
- 白い背景に黒い形状が描かれた画像。
- シルエットやロゴなどのシンプルなデザイン。
- グラデーションのない、はっきりとしたコントラストのある画像。
- ぼかしやノイズのない画像。

これらの条件を満たさない画像でも処理は可能ですが、うまく生成されない場合があります。その場合設定項目の、「斜面生成を無効化」をチェックして、ノーマルマップを生成すると良い結果が得られる場合があります。※うまく生成されない場合もあります。

***入力画像を読み込めない場合***
- 画像の拡張子が`png`または`jpg`、`jpeg`であることを確認してください。
- 画像のサイズが大きすぎる場合、メモリ不足で読み込めないことがあります。解像度を下げて再度試してください。
- 基本的には画像ファイルやパスに日本語が含まれていても対応していますが、環境によっては読み込めない場合があります。その際は、英数字のパスに変更して再度試してください。

---

## 出力ファイル

- 出力されたノーマルマップは PNG 形式で保存されます。
- 詳細設定で出力先ディレクトリを指定した場合はそこに保存し、未指定の場合は入力と同階層に `output` フォルダを作成して保存します。
- 複数回処理を行った場合に上書き保存を行うかどうかは、設定項目の「同名のファイルがある場合上書きして保存」により変更できます。

---

## 設定の保存について

アプリ終了時に以下の設定を保存し、次回起動時に復元します。

- UI 言語
- 出力先ディレクトリ
- 入力プレビューの表示/非表示
- 既定の出力解像度（プレビュー/出力の対象）
- 既定の半径
- 既定の強度
- 既存ファイルを上書き（オン/オフ）

意図的に保存しない項目:

- 入力ファイルのパス（プライバシー・予測可能性のため）

---

## 注意事項

- PNG と JPEG の入力に対応しています。本アプリは入力ファイルを変更・保存しません。
- 入力ファイルが適切でない場合、エラーが発生する可能性があります。推奨される条件を満たす画像を使用してください。
- 処理中はアプリケーションが応答しない場合がありますが、バックグラウンドで処理が進行しています。
- 一部の環境で、ソフトウェアのフォントがインストール済みの別のフォントに置き換わる場合があります。これにより、GUIのレイアウトが崩れることがありますが、機能には影響ありません。
